# 桌面应用与日常页面

主页“添加应用”可以创建指向 NAS 上其他服务的快捷方式，选择名称、地址、内置图标和颜色。它只打开链接，不安装、启动或反向代理应用。

地址支持 HTTP/HTTPS 或当前 NAS 的相对地址。用 `{host}` 表示浏览器正在访问的 NAS 主机，例如 `http://{host}:8096/`，无需把部署 IP 写死。IPv6 地址会正确保留方括号；链接在新标签页打开，不向目标页面提供 opener 或 Referer。

快捷方式对 NAS 成员可见，由管理员编辑；不要在共享地址中填写密码或访问令牌。最多 32 个入口，配置实时生效、重启保留，使用版本校验避免多窗口互相覆盖。只读模式不能修改，拒绝脚本 URL、文件 URL、协议相对地址和 URL 内的账号密码。

追番默认是封面书架、继续观看和剧集卡片。单部番剧的更多菜单放置编辑、暂停与归档等操作。进入“管理追番”后才显示统计、连接与调度、历史和详细下载表格；观看进度、字幕、订阅、去重与媒体文件使用原有后端。

文件、照片、追番和备份以日常使用为主；设备设置、账号、任务审计和高级处理保留管理界面。
