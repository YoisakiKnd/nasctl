# 照片保险箱

本地相册的管理员可以为保险箱设置独立密码。在普通相册打开一张照片，点击锁形按钮，解锁保险箱后选择“确认加密并移入”。密码至少 12 个字符，与 NAS 登录密码独立。忘记保险箱密码无法恢复照片。

照片原文件、缩略图、文件名、拍摄信息和原目录信息均加密保存。每个文件使用独立派生的 AES-256-GCM 密钥，分块认证文件身份、长度和块序号；主密钥随机生成，以 PBKDF2-HMAC-SHA256（600,000 次、随机盐）派生的密码密钥包装。修改密码只重新包装主密钥，并撤销所有保险箱会话。密码和解密密钥不写入日志或浏览器存储。

移入流程先写入加密文件并同步磁盘，再完整解密校验 SHA-256，之后重新核对原文件的内容、大小、修改时间和身份，最后移除原件。不会留下明文回收站副本。源目录必须属于允许写入的 NAS 存储位置；符号链接、硬链接、变化中的原件、只读目录和重叠的相册目录会被拒绝，避免其他相册继续暴露同一照片的缩略图。现阶段支持单张不超过 64 MiB 的照片，最多 10,000 张，每页 48 张；不在 HTTP 请求中扫描或解码图片。

普通索引保留匿名占位行，清除文件名、路径和拍摄元数据，防止旧 ID 被新照片复用；清除对应的已有缩略图。普通列表（包括“显示缺失原文件”）、详情、原图和下载链接均不能访问已移入的照片。若移入中断，加密副本会保留，保险箱明确显示“原件清理未完成”，可以重试；完成前原件可能仍在原目录。重试会再次校验加密副本，不能把中断状态当作成功。

保险箱会话绑定当前 NAS 身份及登录会话，通过 HttpOnly、SameSite=Strict Cookie 传递，15 分钟到期。主动锁定、离开保险箱、最小化窗口或隐藏页面会锁定并清空照片界面；关闭页面时进行尽力锁定，服务器到期检查始终生效。进程重启后所有保险箱会话失效。加密原图支持有界流式解密与 Range 下载，主动锁定后进行中的解密读取也会中断。AI 凭据、普通成员及未解锁的管理员均无权访问。

## 存储与备份

加密文件位于当前 `paths.state_dir/.nasctl-photo-vault`，需要确保状态目录有足够容量。该保留目录禁止通过 nasctl 文件管理器及符号链接访问。操作系统管理员拥有磁盘权限时可以复制密文，仍需要保险箱密码才能解密。

**现有“状态备份”包不包含保险箱照片。** 请停止 nasctl 后，使用文件系统备份同时备份完整状态目录（包括 `.nasctl-photo-vault`）、相册索引和配置，保留文件权限。不要仅复制 `vault.json` 或单个密文文件。密码修改前的备份仍使用当时的保险箱密码。

配置保险箱后，旧的状态包恢复会被拒绝，避免旧相册索引重新暴露移入前的文件名和拍摄信息。此时需要使用完整的离线文件系统备份恢复。已有明文备份、外部同步副本、其他程序缓存和移入前已下载的文件不会被自动清理；加密保险箱不等于对磁盘历史内容进行取证级擦除。

如需取回照片，在已解锁的大图窗口点击“下载原文件”，即可得到与原图字节完全一致的文件。下载后的文件是明文，请自行选择安全位置保存。
