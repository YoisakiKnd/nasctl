# nasctl v0.6.1

修复版：v0.6.0 中“设置”里的页面（概览、系统设置、相册管理、用户与权限、操作记录、追番管理等，
以及“我的”）在电脑上无法滚动，超出一屏的内容看不到。

原因是这些页面的滚动区域被误设成了不可滚动（`overflow: hidden`）。手机尺寸、相册和文件页不受
影响。修复后用真实浏览器在桌面和手机尺寸下逐页验证了滚轮滚动。

从 0.6.0 升级只需替换程序；从更早版本升级请按[升级与迁移](../UPGRADE.md)中的“0.5.x → 0.6.0”
等各节操作。没有配置或数据变化。

## 下载与校验

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7（含常见玩客云 Linux） | `nasctl-linux-armv7.tar.gz` |

```sh
sha256sum -c nasctl-linux-armv7.tar.gz.sha256
tar -xzf nasctl-linux-armv7.tar.gz
cd nasctl-linux-armv7
sha256sum -c SHA256SUMS
```
