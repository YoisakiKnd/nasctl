# nasctl v0.3.0

**从 0.2.x 或 0.1.x 升级前请先阅读 [升级与迁移](../UPGRADE.md)。** 本版本合并了相册程序、移除了
远程相册模式，并重做了网页结构；配置中仍有远程相册键时新版本会拒绝启动。

## 不兼容变化

- **单一程序：** `albumctl` 并入 `nasctl album`（status、scan、thumbs、pause、resume、
  doctor、cache-report、cache-gc、collections），参数不变。安装包只含 `nasctl`。
  相册任务仍在独立进程、私有启动门和 cgroup 内存限制下运行。
- **移除独立相册网页和远程模式：** 不再提供 `albumctl serve`，`[hub.album]` 的
  `api_base`、`token`、`public_url` 与 `mode = "remote"` 需要删除；相册直接读取本地索引。
  `worker_binary` 指向旧 albumctl 时也要删除。
- **systemd：** `albumctl-web.service` 移除；`albumctl-thumbs.{service,timer}` 改为
  `nasctl-album-thumbs.{service,timer}`，以 `nasctl` 用户运行（仍默认不启用）。
- **网页结构：** 多窗口桌面改为“用户页面 + 管理后台”，旧的页面地址会自动跳转。桌面
  搜索框的“搜索应用”移除；用户页面的追番只负责观看，下载操作在“追番管理”中。

配置、状态和缓存路径（`/etc/albumctl`、`/var/lib/albumctl`、`/var/cache/albumctl`）
与已有数据库 schema 均未改变，不需要迁移数据。

## 新功能与改进

- **用户页面：** 首页汇总文件搜索、继续观看、最近照片、存储空间和应用快捷方式；“文件”
  “相册”“追番”专注日常使用；“我的”提供主题（跟随系统／浅色／深色）、修改密码和退出。
  手机使用底部标签栏。
- **管理后台：** 概览、任务中心、追番管理、相册管理、备份、用户与权限、系统设置、操作
  记录，按角色显示；窄屏侧栏收为抽屉。访问过的页面保持挂载，切换时草稿、上传和播放不丢。
- **相册与追番：** 目录配置和限量处理移到“相册管理”；订阅增删改、下载控制、连接与调度、
  元数据和历史集中在“追番管理”。相册从后台返回时会刷新当前页。
- **更轻：** 网页脚本和样式以 gzip 发送（约 332 KB → 109 KB、79 KB → 15 KB），带内容摘要
  的资源长期缓存；ETag 启动时计算一次；systemd 单元设置 `GOMEMLIMIT=96MiB` 软上限；
  深色模式首屏不再闪白；样式表移除桌面布局并合并为一套设计 token。
- `nasctl --config PATH album …` 与其他命令一样支持全局参数写在前面。

## 下载与校验

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7 | `nasctl-linux-armv7.tar.gz` |

每包包含 `nasctl`、配置样例、systemd 单元（`nasctl-web` 与 `nasctl-album-thumbs`）、部署与
升级文档和内部校验清单。同时下载对应 `.sha256` 文件；以下以 arm64 为例：

```sh
sha256sum -c nasctl-linux-arm64.tar.gz.sha256
tar -xzf nasctl-linux-arm64.tar.gz
cd nasctl-linux-arm64
sha256sum -c SHA256SUMS
```

新部署按包内 `docs/DEPLOYMENT.md` 完成初始化和账号设置。已有 0.2.x／0.1.x 部署按 `docs/UPGRADE.md`：
先用旧版建立并验证私有状态检查点，再修改配置、替换程序和单元。

## 验证范围

发布提交要求 main 上的完整 GitHub CI 已通过，包括 Go 测试／竞态、前端工作流、真实
Linux systemd/cgroup 相册处理及 ARMv7 模拟器冒烟。正式包另核对静态架构、版本标识、
所有文件 SHA-256 和上传后的下载字节。

实际 NAS 的资源／编码样本、磁盘满、挂载断开、断电恢复及真实 qBittorrent／TMDB 账号
仍需在目标环境验证；交叉编译和生成测试数据不能替代这些实测。
