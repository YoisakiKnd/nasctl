# nasctl v0.8.0

存储与共享：借鉴 CasaOS 的存储页面，在网页里管理磁盘、USB 设备、局域网共享和网络存储。
控制台仍以普通用户在沙箱里运行；需要 root 的操作交给一个**按需启动、做完就退出**的存储
助手，没有常驻的 root 进程。从 0.7.x 升级只需替换程序；启用存储助手请看
[STORAGE.md](../STORAGE.md)。

## 新增与改进

- **设置 › 存储与共享：**
  - 磁盘卡片：型号、容量、接口（USB / SATA / NVMe / 存储卡）、序列号、每个分区的文件系统、
    挂载位置和已用空间。系统盘明确标出，不提供任何修改操作。
  - 硬盘健康：一键读取 SMART（需要 smartmontools），显示健康结论、温度、通电时间、
    重映射和待处理扇区，NVMe 显示寿命已用。
  - 挂载与卸载：挂载到 `/media/nasctl/名称`，可设为开机自动挂载（写入 `/etc/fstab` 中由
    nasctl 维护的区块，按 UUID、带 `nofail`，磁盘不在时不影响开机）。
  - USB 自动挂载：插入即挂载到 `/media/nasctl/卷标`，拔出自动卸载；默认关闭。
  - 格式化：整块非系统盘格式化为 ext4 并挂载，必须输入磁盘序列号确认。
  - 局域网共享（Samba）：添加共享文件夹，选择只读或可写、需要密码或访客访问；配置先经
    `testparm` 校验再生效，文件始终归 nasctl 服务用户。
  - 网络存储：把其他 NAS／电脑的 SMB 或 NFS 共享挂到 `/media/nasctl`，账号密码只保存在
    root 专属的凭据文件里。
- **存储助手：** `nasctl storage-helper`，由 `nasctl-storage.socket` 按连接启动。它自己校验
  每个请求（系统盘、挂载位置、文件系统类型、共享目录范围、名称格式），不信任控制台。
  每次修改都写入操作记录，密码不会进入记录。
- **新接口：** `GET /api/v1/storage`、`GET /api/v1/storage/smart`、
  `POST /api/v1/storage/{action}`，仅管理员可用，修改需要确认头。

## 兼容性

- 配置文件、数据库和状态目录格式没有变化，可以直接替换程序，也可以换回 0.7.x。
- 不安装存储助手时，新页面只显示启用方法，其他功能完全不受影响。
- `nasctl-web.service` 增加了 `ReadWritePaths=-/media/nasctl`；只在使用存储助手时需要更新。
- 发布包新增 `systemd/nasctl-storage.socket`、`nasctl-storage@.service`、
  `nasctl-storage-automount@.service`、`udev/99-nasctl-automount.rules`、
  `tmpfiles/nasctl.conf` 和 `docs/STORAGE.md`。

## 下载与校验

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7（含常见玩客云 Linux） | `nasctl-linux-armv7.tar.gz` |

```sh
sha256sum -c nasctl-linux-armv7.tar.gz.sha256
tar -xzf nasctl-linux-armv7.tar.gz
cd nasctl-linux-armv7
sha256sum -c SHA256SUMS
```

## 验证范围

发布提交要求 main 上的完整 GitHub CI 已通过（Go 测试／竞态、前端完整工作流、ARMv7 等）。

- 助手的每项检查都有单元测试：拒绝系统盘、已挂载分区、不支持的文件系统、危险名称，
  fstab 区块的增删和原样还原，Samba 配置的生成、校验失败回滚，凭据文件权限，密码不落盘。
- 真实 Linux（systemd 255）：socket 按连接启动 root 助手；对一块 512 MB 的网络块设备完成
  分区、格式化、挂载、开机挂载写入与还原；在与 nasctl-web 相同沙箱设置的服务里能连上助手，
  并能看到、写入它启动之后才挂载的磁盘。
- Samba：在 Ubuntu 24.04 容器里用 smbclient 验证密码共享读写（文件归 nasctl）、错误密码被拒、
  访客共享只读、系统目录拒绝共享。
- 页面在真实浏览器中按电脑和手机尺寸、浅色和深色检查过布局和滚动。
- 需要在目标设备上确认：USB 自动挂载（udev 事件）、SMART（很多 USB 硬盘盒不转发）、
  真实 SMB／NFS 服务器、NTFS／exFAT 驱动。
