# nasctl v0.8.1

文件页可以查看和编辑文本、解压 ZIP；大图片也能生成缩略图；修复在玩客云（ARMv7）上实测
存储助手时发现的问题；几处会让控制台内存超出上限的地方改为流式处理。从 0.8.0 升级只需替换
程序，配置和数据格式没有变化。

## 新增与改进

- **查看与编辑文本：** `.txt`、`.md`、`.log`、`.json`、`.yaml`、`.conf`、字幕、脚本等在详情栏显示
  开头一段，打开后显示全文；可写的存储目录里可以直接编辑（Ctrl+S 保存，有未保存修改时关闭会
  先确认）。工具栏新增“新建文件”。保存时核对文件是否在你打开后被改过，改过就拒绝而不覆盖；
  先写临时文件再原子替换，保留原权限。最多 1 MiB，非 UTF-8 文件提示下载。见
  [FILES.md](../FILES.md#查看与编辑文本)。
- **解压 ZIP：** `.zip` 的右键菜单和详情栏提供“解压”，后台解压到一个新文件夹，不覆盖已有内容，
  全部完成并校验后才出现。拒绝 `../` 等不安全路径；中文 Windows 打包的 GBK 文件名、WinRAR／
  7-Zip 的 Unicode 文件名都能正确还原；加密的压缩包会说明原因。见
  [FILES.md](../FILES.md#解压-zip)。
- **大图片也有缩略图：** 渐进式 JPEG 只保留缩小解码用得到的数据，PNG 改为边读边缩小（隔行
  扫描也一样）。1600 万像素的渐进式 JPEG 从约 100 MB 降到约 12 MB，5200 万像素的 PNG 从约
  210 MB 降到约 14 MB。之前因超出预算被跳过、或在内存上限处被停下的照片，升级后第一次扫描
  会自动重新排队，在后台照常生成。PNG 不再交给 libvips。
- **手机上点文件直接打开**，长按出操作菜单；关闭预览后详情栏自动收起。
- **任务面板和任务中心**显示中文操作名称（“复制”“解压”等），文件错误先给中文说明，原文放在
  详情里。

## 修复

- **存储助手（玩客云 ARMv7 实测）：**
  - 32 位设备上读取 SMART 时数值溢出；USB 硬盘盒提示“Unknown USB bridge”时自动改用 SAT 方式。
  - 有内核 `ntfs3` 驱动时优先使用；使用 ntfs-3g 时改由 `systemd-mount` 挂载，不再随助手退出而被
    卸载。
  - 外部命令留下子进程时助手不再卡住。
  - 放有正在使用的交换文件的分区标为系统盘，不提供卸载和格式化。
  - USB 自动挂载跳过你自己写在 `/etc/fstab` 里的分区；同一磁盘重复设置开机挂载时替换旧条目；
    改写 `/etc/fstab` 时保留文件权限。
  - Samba 共享名与 `smb.conf` 里已有的共享同名时拒绝，不再生成冲突配置。
  - NFS 服务器无响应时快速失败并给出明确提示，不再长时间挂起。
- **存储页的启用步骤**补上了让控制台能写入已挂载磁盘的一步（独立的 drop-in 文件，不改动你自己
  修改过的服务单元）。
- **相册页**的“照片／相簿／保险箱”标签栏在手机上不再透出壁纸、选中项不再被裁掉。
- **首页**没有自定义壁纸时，浏览器控制台不再每次记录一条 404。

## 内存

控制台的目标是常驻不超过 40 MiB。这一版按并发负载逐项测过峰值（amd64）：

| 场景 | 0.8.0 | 0.8.1 |
| --- | --- | --- |
| 同时上传 4 张 12 MB 壁纸 | 104 MiB（超过单元的 `MemoryMax=96M`） | 22 MiB |
| 16 个请求同时查看、保存 1 MiB 文本 | 71 MiB（该功能为本版新增，按开发中版本测量） | 31 MiB |
| 解压 5001 个文件、共 200 MB 的 ZIP | — | 28.5 MiB |

壁纸上传改为边收边写盘；文本以原始字节返回，同一时刻最多两个请求把文件放在内存里。

## 兼容性

- 配置文件、数据库和状态目录格式没有变化，可以直接替换程序，也可以换回 0.8.0。
- 相册的解码策略版本升为 3：升级后第一次扫描会把之前跳过或被内存上限停下的照片重新排队一次。
- 新接口：`GET/PUT /api/v1/files/text`、`POST /api/v1/files/extract`（后台任务 `files.extract`）；
  `GET /api/v1/desktop/wallpaper?exists=1`。
- 新依赖 `golang.org/x/text`（原已在依赖图中，用于 GBK 文件名），ARMv7 程序增大约 190 KB。

## 下载与校验

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7（含常见玩客云 Linux） | `nasctl-linux-armv7.tar.gz` |

```sh
sha256sum -c nasctl-linux-armv7.tar.gz.sha256
tar -xzf nasctl-linux-armv7.tar.gz
cd nasctl-linux-armv7
sha256sum -c SHA256SUMS
```

## 验证范围

发布提交要求 main 上的完整 GitHub CI 已通过（Go 测试／竞态、前端完整工作流、ARMv7 等）。

- 文本编辑与 ZIP 解压各有单元测试、HTTP 测试和 CI 中的页面测试（`text-editor.mjs`、
  `extract.mjs`）：冲突拒绝、原子替换、不安全路径、压缩炸弹、损坏和加密的压缩包。
- PNG 缩略图与 Go 标准库的解码结果逐像素一致（PngSuite、各类型和位深的隔行文件、随机图像）；
  渐进式 JPEG 的精简存储与保留全部系数时逐像素一致；32 位构建同样通过。
- 在玩客云（S805，ARMv7）上用新解码器处理设备上此前没有缩略图的 12 张真实照片：全部成功，
  每张峰值 7.7～15.3 MiB、1.7～14.6 秒。
- 存储助手在同一台玩客云上用网络块设备测试了分区、格式化、挂载和 SMART，没有动用真实数据盘。
- 页面在真实浏览器中按电脑和手机尺寸检查过布局。
- 尚未在设备上确认：USB 自动挂载的插拔事件（设备没有空闲的 USB 口）；ARM 上的并发内存峰值
  只测了缩略图。
