# nasctl v0.5.0

私密目录与设置页改版。照片和视频可以留在原来的硬盘位置，用保险箱密码保护，不必再加密
搬到系统盘；系统设置、相册管理、保险箱和“我的”页面重新设计。从 0.4.x 升级只需替换程序；
从更早版本升级请先阅读[升级与迁移](../UPGRADE.md)。

## 新增与改进

- **私密目录：** 在“相册管理”添加或编辑目录时打开“设为私密目录”。文件不移动、不加密、
  不占系统盘；保险箱锁定时，普通相册、文件页的列表、搜索和回收站里都看不到它们，直接访问
  路径（包括经由符号链接）也会被拒绝。解锁后在“相册 › 保险箱 › 私密目录”浏览照片和视频，
  文件页里私密目录带锁形标记，可以照常浏览和整理。私密目录本身及其上级文件夹不能被整体
  移动、重命名、删除、复制或打包，避免文件被意外带出保护范围。
- **改动私密设置需要密码：** 设置、修改、取消或移除私密目录都要先解锁保险箱，其他能管理
  相册的账号无法关掉保护。私密目录不能与普通相册目录互相包含，保存时会指出冲突的目录。
- **保险箱更顺手：** 解锁状态在相册、文件页和管理后台之间共享，右上角显示“已解锁”，点一下
  即可锁定；改为闲置 15 分钟自动锁定（查看内容会重新计时，长视频不会中途锁住），标签页隐藏
  超过 2 分钟或关闭页面仍会锁定。文件页和目录编辑框里可以就地输入密码解锁。
- **系统设置改版：** 左侧分区导航（手机上为顶部标签），每个分区一张卡片；开关代替复选框，
  字节和内存数值旁显示换算后的大小（如“≈ 8 GiB”）；底部保存栏显示是否有未保存的修改，
  可以一键放弃修改。校验后保存、重启生效的流程不变。
- **相册管理改版：** 顶部概览数字，目录以卡片列出（私密目录有专门标记），添加和编辑在对话框
  中进行；限量处理的运行时间改为下拉选择。
- **“我的”页面：** 主题以预览卡片选择，新增保险箱状态和一键锁定。
- **相册页面** 与顶部导航对齐，照片网格加了间距和圆角；手机上仍然贴边显示。

## 兼容性

- 配置文件、数据库和状态目录格式没有不兼容变化。主配置 `[[collections]]` 新增可选键
  `private`（默认 `false`）。
- 保险箱 Cookie 的路径从 `/api/v1/album/vault` 改为 `/api/v1`，仍为 HttpOnly、SameSite=Strict
  的会话 Cookie。
- 文件 API 遇到私密目录时返回 `403 vault_locked` 或 `409 private_folder`；新增
  `/api/v1/album/private/…` 读取私密目录的相册内容。
- **回滚到 0.4.x 前，要先取消所有私密目录**，否则 0.4.x 无法读取相册目录配置。详见
  [升级与迁移](../UPGRADE.md#回滚到-04x)。

## 下载与校验

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7（含常见玩客云 Linux） | `nasctl-linux-armv7.tar.gz` |

```sh
sha256sum -c nasctl-linux-armv7.tar.gz.sha256
tar -xzf nasctl-linux-armv7.tar.gz
cd nasctl-linux-armv7
sha256sum -c SHA256SUMS
```

升级步骤见包内 `docs/UPGRADE.md`，私密目录的用法和保护范围见 `docs/PHOTO-VAULT.md`。
