# nasctl v0.2.0

本版完善日常相册、追番和备份体验，新增加密照片保险箱、WebDAV 备份与桌面自定义应用。
提供 Linux amd64、arm64、ARMv7 三架构静态正式安装包。

## 新增与改进

- 相册改为照片时间线、网格和大图查看，支持照片与视频浏览。
- 照片保险箱使用独立密码，加密原文件、缩略图及照片元数据；支持加密校验后的原件清理、中断重试和自动锁定。
- WebDAV 普通文件备份原样上传，保留目录结构；私密备份使用 Go tar、zstd 和独立密码加密，生成 `.tar.zst.age`。提供回读校验、失败重试及拒绝覆盖的网页恢复。
- 可备份照片保险箱的完整密文，并用独立备份密码保护外层归档；普通文件备份保留本地原文件。
- 追番默认显示海报书架、继续观看和剧集卡片，详细下载与维护操作集中到“管理追番”。
- 添加订阅支持直接搜索 Mikan，或搜索 Bangumi 后选择对应 Mikan 条目和字幕组。选源填入草稿，确认后才保存；自动下载默认关闭，手动 RSS 保留。
- 主页支持自定义应用快捷方式、图标和颜色，地址可使用 `{host}`，桌面搜索可直接打开匹配的应用。
- 补充玩客云上的 Emby／Jellyfin 兼容性与原生客户端直播放方案说明。

## 下载与升级

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7（含常见玩客云 Linux） | `nasctl-linux-armv7.tar.gz` |

同时下载对应 `.sha256` 文件，先校验压缩包，再校验解包后的内部清单：

```sh
sha256sum -c nasctl-linux-armv7.tar.gz.sha256
tar -xzf nasctl-linux-armv7.tar.gz
cd nasctl-linux-armv7
sha256sum -c SHA256SUMS
```

每包包含同版本 `nasctl` 与 `albumctl`、配置样例、systemd 单元、部署与功能文档及依赖许可。
日常启动 `nasctl`；将匹配的 `albumctl` 放在同一安装目录，用于按需执行受限相册处理任务。
目标 NAS 无需 Node、Python 或外部 zstd／age 命令即可使用备份和网页恢复。

已有部署先备份配置、状态和媒体，再停止服务并同时替换两个程序，保留现有配置与数据目录。
具体步骤见包内 `docs/DEPLOYMENT.md`。

## 数据与密码说明

- 照片移入保险箱会在完成密文校验后清理原件；备份完整保险箱密文，并保管独立密码。普通离线状态包不包含保险箱照片，恢复与回滚按 `docs/PHOTO-VAULT.md` 操作。
- WebDAV 登录密码保存在本机私有配置，离线状态包不包含该凭据；恢复后重新填写连接。
- 加密备份包密码不保存。保险箱备份外层使用备份密码，内层照片仍需原保险箱密码。
- Bangumi 用于查找番剧，下载 RSS 来自 Mikan；本地封面与 NFO 刮削仍沿用原 TMDB 配置。

## 验证范围

发布提交须通过 main 上的完整 GitHub CI：Go 测试与 race、前端完整工作流、来源搜索与选源确认、
WebDAV 两种上传和恢复、照片保险箱、Linux systemd/cgroup 处理及 ARMv7 模拟启动。
正式包另外核对静态架构、无 `-dev` 版本标识、完整提交和全部 SHA-256，并回读发布后的上传字节。

真实 NAS 的性能、设备固件、实际下载器／WebDAV 兼容性及硬件断电场景仍需目标环境验证。
本版不会自动安装 Emby／Jellyfin；应用快捷方式只打开已有服务。
