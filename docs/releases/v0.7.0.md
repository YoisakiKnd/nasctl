# nasctl v0.7.0

CasaOS 风格的桌面首页。底座仍是 nasctl 的单一程序：不依赖 Docker，不增加常驻进程。从 0.6.x
升级只需替换程序；从更早版本升级请先阅读[升级与迁移](../UPGRADE.md)。

## 新增与改进

- **桌面首页：** 首页直接铺在壁纸上，玻璃质感的卡片。
  - 左侧小组件：时钟、系统状态（CPU、内存环形图，有温度传感器时显示温度）、存储空间、
    网络实时速度和曲线。“小组件设置”里可以逐个开关，也能设置搜索框默认搜什么。
  - 右侧是搜索框：默认搜 NAS 里的文件，可切换为百度、必应、Google 搜网页。
  - 应用图标：文件、相册、追番、备份、任务中心、设置，加上管理员添加的外部应用。
  - 手机上应用排在前面，小组件在下面。
- **壁纸：** 内置 6 张（晴空、雪山、极光、暮色、森林、石墨），在“设置 › 账号与外观”里选择，
  整个界面都会换上。管理员可以上传一张自定义壁纸给所有成员使用，大图会在浏览器里缩小后
  再上传。
- **系统状态接口：** 新增 `GET /api/v1/system/status`。只在有人看桌面时按请求读取 /proc 和 /sys，
  没有后台采样，空闲时不占资源。

## 兼容性

- 配置文件、数据库和状态目录格式都没有变化，可以直接替换程序，也可以直接换回 0.6.x。
- 新增状态文件 `desktop-wallpaper`（上传自定义壁纸后才有）。
- 首页的“存储空间”和“我的应用”卡片换成了桌面小组件和应用网格。

## 接下来

计划借鉴 CasaOS 的存储管理（磁盘与健康状态、挂载、USB 自动挂载）、Samba 共享和文件预览增强。

## 下载与校验

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7（含常见玩客云 Linux） | `nasctl-linux-armv7.tar.gz` |

```sh
sha256sum -c nasctl-linux-armv7.tar.gz.sha256
tar -xzf nasctl-linux-armv7.tar.gz
cd nasctl-linux-armv7
sha256sum -c SHA256SUMS
```

## 验证范围

发布提交要求 main 上的完整 GitHub CI 已通过（Go 测试／竞态、前端完整工作流、ARMv7 等）。
桌面在真实浏览器中按电脑和手机尺寸检查过布局和滚动；系统状态的计算用模拟的 /proc 数据测试。
真实设备上的温度传感器和网卡命名因板子而异，需要在目标设备上确认。
