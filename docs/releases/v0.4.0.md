# nasctl v0.4.0

日常可用性版本：报错能说清原因，大文件和文件夹下载更可靠，登录可以保持，手机上可以像
App 一样打开。从 0.3.x 升级只需替换程序，不需要改配置；从更早版本升级请先阅读
[升级与迁移](../UPGRADE.md)。

## 新增与改进

- **看得懂的报错：** 所有报错第一行是摘要，点“查看详情”可看到技术细节并一键复制。WebDAV
  备份失败会说明是哪一步（建立目录、上传、回读校验、改名等）、HTTP 状态、服务器要求的跳转、
  服务器回复的开头，并按状态码给出建议；备份记录本身也保存这些原因。原来的英文报错改为中文，
  英文原文放在详情里。内部错误原文只给设备管理员看。
- **WebDAV 兼容：** 建立、移动和删除远端目录时地址以 `/` 结尾，兼容 nginx 自带的 WebDAV 模块。
- **大文件下载不再中断：** 下载、预览、视频播放和保险箱原图改为“30 秒没有进展才断开”。
  此前任何超过 60 秒的传输都会被服务器写超时切断。
- **文件夹打包下载：** 选中文件夹可以下载为 ZIP（不压缩，几乎不占 CPU）。先检查条目数和
  大小，超过复制上限时直接提示，不会生成半截的压缩包；不跟随链接，不包含隐藏和内部文件。
- **拖放上传：** 把文件拖到文件页即可上传到当前目录，文件夹会被跳过并提示。
- **保持登录 30 天：** 账号登录时可选，服务重启后仍有效；只保存 Cookie 摘要，退出登录、
  修改密码或角色会立即失效。默认不勾选，行为与之前相同。
- **账号菜单：** 右上角头像打开菜单：账号与外观、管理后台、主题（跟随系统／浅色／深色）、
  退出登录。
- **添加到主屏幕：** 提供网页应用清单和图标，手机和电脑都可以把 nasctl 安装为独立窗口。
- **UI 库：** 交互组件采用 Bits UI（Svelte 5 无样式组件库），外观仍沿用现有设计。

## 兼容性

- 配置文件、数据库和状态目录格式都没有变化，0.3.x 可直接替换程序。
- 新增状态文件 `remembered-sessions.json`（首次有人勾选“保持登录”时创建，权限 0600）。
- API 的 `message` 改为中文；脚本请按 `error` 字段的错误代码判断。
- 新增公开的 `/manifest.webmanifest` 和应用图标路径，不含任何私有信息。

## 下载与校验

| 架构 | 安装包 |
| --- | --- |
| x86_64 | `nasctl-linux-amd64.tar.gz` |
| aarch64 | `nasctl-linux-arm64.tar.gz` |
| ARMv7（含常见玩客云 Linux） | `nasctl-linux-armv7.tar.gz` |

```sh
sha256sum -c nasctl-linux-armv7.tar.gz.sha256
tar -xzf nasctl-linux-armv7.tar.gz
cd nasctl-linux-armv7
sha256sum -c SHA256SUMS
```

升级步骤见包内 `docs/UPGRADE.md`。
