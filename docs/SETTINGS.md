# 设备配置与真实容量

“设置 → 设备配置”提供存储目录、文件预算、原生追番、下载器秘密、内存阈值和任务／
审计保留设置。先校验，核对确认后保存。修改草稿会让旧的校验结果失效；并发修改按
完整版本摘要拒绝过期保存，页面保留当前草稿供审阅。

当前运行值和已保存值分开显示。保存到 `state_dir/nasctl-settings.json`，权限 0600、
最多 64 KiB，原基础 TOML 保留。**需要重启 nasctl 生效**，不会自动终止任务、重启
服务或热替换正在进行的文件操作。空闲后重启即可；独立 nasctl CLI 同样加载覆盖值。
相册处理组件只接收启动层产生的隔离配置，不自行载入此覆盖文件。

移除存储目录配置不删除文件。已有托管相册引用某目录时，先移除该托管相册配置，再
移除存储根；避免下次启动出现悬空引用。基础 TOML 中的照片集合继续保留。修改后的
重复根、状态／缓存／私有目录暴露、相对路径和预算冲突均由服务端完整校验。
本页不提供任意 shell，也不会替你挂载设备或在缺失卷上创建空媒体目录。

下载器用户名、密码和 TMDB 令牌只显示是否设置，输入新值后可明确保留／替换／清除。
秘密不返回响应、不会写入任务参数或前端持久存储，保存后清空新值输入框。监听凭据
与 AI 凭据仍由基础 TOML 管理。只读控制台不能校验或保存修改；AI 凭据不能进入统一
设置。保存经运行模式／身份／确认／任务与审计层，记录版本摘要，不记录秘密或整份配置。

覆盖文件包含秘密，请保持私有；它参与离线服务状态包和恢复，详见 STATE-BACKUPS.md。
基础 TOML 被手动更改时也会使保存摘要失效。损坏的覆盖文件拒绝加载。先停止全部状态
写入进程，再由 NAS 本机操作者运行 `nasctl --config 配置路径 settings reset --confirm`。
它保留覆盖文件原件到私有 `state_dir/local-recovery/<编号>/original.raw`，下次启动使用
基础 TOML；不修改原 TOML、账号或媒体。该路径不依赖设置覆盖文件与任务数据库，
仍受离线独占锁和未处理状态恢复日志约束。恢复记录最多 16 次，与账号修复共用上限；
满后先自行审阅并移到私有离线存储。不要公开包含秘密的原件。首次设置与账号恢复见 AUTH.md。

## 容量含义

桌面、概览和文件窗口的可用空间来自已打开目录所在文件系统的 `fstatfs`，无需扫描
目录。显示总空间、总已用和当前进程可用空间；文件系统保留空间可能使“总量减已用”
大于进程可用空间。它不是目录大小或目录配额。共用同一文件系统的目录有相同卷标识，
概览注明共用，不能把这些容量相加当成多块磁盘。读取失败明确显示未知，不用 0 代替。

目录或挂载被替换时，打开句柄与当前配置路径身份不一致，读／写和容量均拒绝继续使用
旧目录；重新连接需重启服务。文件窗口刷新和完成操作后会重新读取容量。实际挂载变化
还需 NAS 环境验收，合成测试不能代替物理拔盘或文件系统配额测试。

Linux 的内存、交换空间和压力信号由原有 /proc 采样与资源保护提供；macOS 缺少这些
Linux 信号时明确显示未知，不伪造内存利用率，也不会因此放行相册解码。

## API 与验证

| 路由 | 行为 |
| --- | --- |
| `GET /api/v1/settings` | 脱敏的 active／saved、秘密存在标记、版本摘要、重启需求 |
| `POST /api/v1/settings/validate` | `revision,settings,secrets`，完整校验，无保存副作用 |
| `POST /api/v1/settings` | 同上并要求 `X-Nasctl-Confirm: 1`，原子保存私有覆盖文件 |

`secrets` 使用 `username/password/tmdb_token: {action: keep|set|clear, value?: ...}`；
保留／清除时不能同时提交值。未知字段、超限、旧版本和错误身份拒绝。每项预算及内存
阈值仍受配置自身上限约束；页面不能关闭基础配置的 cgroup 隔离要求。

本机 Go 竞态验证配置保存／秘密处理／重新加载、基础 TOML 不变、相册隔离、托管引用、
并发版本和离线锁；HTTP 验证确认、只读／AI 拒绝、脱敏和审计；真实服务＋编译 Svelte
DOM 验证草稿修改使确认失效、保存／当前值区分和原文件字节。浏览器桌面及 366px
手机布局已检查。实际重启后，目录名称和上传上限生效，等待重启标记清除，原文件和
秘密脱敏保持正确。审计除保留天数外，还有 100000 行硬上限；同一天高频写入的真实
插入测试通过。CI 增加合成及实际重启脚本，尚未据此声称远程 CI 已运行。
