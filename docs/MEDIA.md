# 追番媒体库与播放

追番归档的单集可在“剧集与媒体库”中播放、下载和标记观看状态。浏览器直接读取
原文件，支持 HTTP Range，不启动转码器或扫描器。编码支持由浏览器决定；无法播放
时显示说明，仍可下载到外部播放器使用。

## 观看记录

- 打开未看完的剧集时，读取 SQLite 中的上次位置，媒体元数据就绪后恢复播放位置。
- 播放中最多每 15 秒保存一次，暂停、播放结束和关闭播放器时也保存。记录为单一
  操作者共享，不区分多个账号；同时在多处播放时，最后保存的状态生效。
- 播放位置达到时长的 95% 后标记为已看完；往回拖动不会自动清除已看完标记。
- 可以手动“标记看完”。“标记未看”会清除已看完标记并将播放位置重置为零。
- 支持“继续观看”“未看完”“已看完”筛选，继续观看按最近保存时间排序。
- 关闭时保存失败会保留播放器并显示错误，可以重试或选择“放弃本次进度并关闭”。
  直接关闭浏览器／导航离开时尝试保存，但网络断开或进程退出不能保证最后一次请求
  成功；此前确认保存的位置仍保留。
- 只读模式或 AI 凭据可播放和读取记录，不自动保存或修改观看状态。
- 状态保存不联系 RSS、TMDB 或下载器，不受订阅暂停影响；不会改变下载与归档状态。
  自动位置保存不逐次写审计；显式标记看完／未看会记录审计。

每条记录只增加固定的四个字段；时长与位置必须有限、非负且位置不超过时长，
最大时长 24 小时。数据库 schema 2 在事务中升级至当前 schema 4，旧剧集默认未观看，
订阅、下载和归档信息保留。旧二进制不能读取新 schema；回退前应恢复对应的状态
备份，不要只复制正在写入的 SQLite 主文件而忽略 WAL。

## 字幕

播放器只列出该剧集视频同目录、同文件名主体的外挂字幕。例如：

```text
某番剧 S01E01.mp4
某番剧 S01E01.chs.srt
某番剧 S01E01.en.vtt
某番剧 S01E01.ass
```

UTF-8 SRT 在读取时转换为 WebVTT，不改写库内文件；UTF-8 VTT 直接用于字幕轨道。
选择字幕后明确启用浏览器轨道，选“不显示外挂字幕”可关闭。ASS／SSA 或其他编码的
字幕可下载原文件到外部播放器使用；不提取视频内嵌字幕，也不在服务器渲染 ASS。

浏览器字幕读取最多 1 MiB、20000 行；超限可以下载原文件。目录读取最多 4096 个
条目，最多列出 30 个匹配字幕，触及上限会明确提示。文件通过 `os.Root` 打开，拒绝
最终文件符号链接、非普通文件以及另一个剧集的字幕。所有传输共享并发上限。

## 封面

订阅卡片显示此前 TMDB 刮削保存的 `番剧/poster.jpg`。封面从 NAS 自身接口读取，
打开页面不会发起刮削或向浏览器引入外部图片域名。最多读取 2 MiB 的普通 JPEG 文件，
只检查文件头，不在 NAS 解码图片。没有封面或读取失败时显示番剧首字。

## HTTP API

| 路由 | 用途 |
| --- | --- |
| `GET /api/v1/anime/episodes?watch=in_progress` | 继续观看；还支持 watched、unwatched，可组合 subscription、state 和分页 |
| `GET /api/v1/anime/episodes/{id}/playback` | 已入库剧集的观看信息、外挂字幕列表及截断标记 |
| `PUT /api/v1/anime/episodes/{id}/playback` | 保存位置／时长，或显式设置 watched；仅操作者可写 |
| `GET /api/v1/anime/episodes/{id}/subtitles/{name}` | 读取该单集的 SRT／VTT，返回 text/vtt |
| `GET /api/v1/anime/episodes/{id}/subtitles/{name}?download=1` | 下载原始字幕，支持 ASS／SSA |
| `GET /api/v1/anime/subscriptions/{id}/poster` | 读取已刮削的本地封面 |

保存播放位置的 JSON 是 `{"position":120.5,"duration":1440}`；两项必须一起提供。
显式标记使用 `{"watched":true}`，重置使用 `{"watched":false,"position":0,"duration":0}`。
这些接口沿用网页会话／Bearer 认证和同源检查，不接受服务器的绝对文件路径。

## 验证

Go 测试覆盖观看状态持久化与筛选、下载同步不能覆盖观看记录、迁移保留旧数据、
字幕转换上限和编码、文件边界、私有媒体认证、操作者／AI／只读权限、并发传输
饱和时及时返回、视频 Range 与原字幕下载。

`scripts/uitest/media.mjs` 以模拟媒体时钟驱动实际编译的 Svelte 前端，连接隔离 Go
服务验证恢复位置、暂停保存、自动完成、手动重置、筛选、字幕启用及保存失败交互。
CI 中的媒体文件为 HTTP／DOM 占位样例，不能据此证明编码播放正常。

另外使用 macOS 系统编码器生成的 20 秒 H.264 视频，在实际浏览器验证解码、播放、
暂停、服务重启后恢复到第 17 秒，以及 SRT 中文字幕实际显示。测试封面是合成 JPEG。
这些证据仍不能替代真实下载器、真实番剧编码、跨盘归档或目标 NAS 资源测量。
