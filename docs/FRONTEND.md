# Svelte 桌面与视觉方案

2026-10-14 按用户提供的 CasaOS 桌面和 P2 文件管理器参考图，与本机 agy 的
Claude Opus 5.5 (High) 进行文字评审，先列计划，再实施。只发送整理后的视觉需求、
已有功能和资源边界，没有发送源码、凭据、实际文件路径或授予项目目录访问权限。
最终计划及取舍见 [FRONTEND-REDESIGN.md](FRONTEND-REDESIGN.md)。

## 视觉与布局

- 原创内置山景 SVG，浅色黎明、深色暮色共用一份图形，无滤镜、外链图片或装饰动画。
- 桌面左侧是时钟、真实内存／资源状态、存储目录组件；右侧是搜索、应用图标和任务摘要。
  没有可靠数据就显示未获取，不画假 CPU、网络吞吐或磁盘容量。
- 组件使用少量透明表面，窗口内容保持不透明；不使用大面积 backdrop-filter。
  应用使用同色系渐变图标、内联 SVG 和系统字体，不引入大型 UI 库或在线字体。
- 保留七个应用入口。窗口标题栏 36px，支持拖动、右下角缩放、双击最大化、最小化和
  底部切换，标题与缩放柄支持方向键。手机聚焦应用全屏，保留底部切换。
- 文件窗口全铺满内部，采用位置栏、位置标签、导航与路径、网格／列表及详情栏。
  选择、键盘、最近使用、固定目录、分页和操作入口见 [FILES.md](FILES.md)。
- 页面使用中文；备份仍明确标识未接入。相册仍通过显式配置的独立服务浏览，
  后端直接整合尚待继续，不用视觉改版掩盖现状，见 [ALBUM.md](ALBUM.md)。

## 交互保留与运行成本

多窗口切换、最小化和显示桌面保留挂载状态，包括未保存草稿、上传与播放。窗口中的
对话框只覆盖所属应用，其他应用仍可操作；关闭窗口先调用应用已有的关闭保护。
登录前不挂载受保护内容，退出或 API 会话失效时卸载全部功能窗口并清空桌面查询。
认证边界见 [AUTH.md](AUTH.md)。

前端编译产物在 internal/hubweb/web，Go 直接嵌入；部署不跑 Node。修改前端才需要在
开发机执行 npm ci、npm run check、npm run build。构建给脚本／样式 URL 添加内容摘要。
API 默认 20 秒超时，卸载取消请求；最小化窗口、手机后台窗口和浏览器隐藏时跳过轮询，
桌面状态共用一次 15 秒轮询。浏览不会发起媒体扫描、解码或转码。

追番保留 RSS 预览、集数范围、连接检查、暂停／归档恢复、TMDB 选择、媒体库、续播和
字幕等已有能力；播放器保存失败时保留重试或明确放弃入口。详见
[ANIME.md](ANIME.md)、[MEDIA.md](MEDIA.md)。

浏览器仅保存主题、文件视图偏好及用户明确固定的目录元数据。标签、最近使用、草稿
只在当前应用实例中保留；不向 localStorage 写入令牌或文件内容。网盘后续按需接入。

## 验证

Svelte 检查要求零错误、零警告。DOM 使用真实编译脚本和隔离 Go 服务，验证原有七个
入口、登录与草稿保护、多窗口，以及新文件管理器的选择／打开、历史、位置标签、
固定／最近使用、网格／列表、键盘菜单、桌面应用和文件搜索。文件写入测试通过真实
XHR／HTTP 检查上传字节、同名冲突、复制移动、回收恢复和永久删除的准确名称确认。

真实浏览器另外检查桌面、文件网格／预览、深色和手机布局。jsdom 不提供视觉或编码
播放证据；真实 NAS 资源、真实下载器、Linux 全量测试和长期运行仍需部署验证。
