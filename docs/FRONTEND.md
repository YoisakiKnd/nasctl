# Svelte 用户页面与管理后台

2026-10-16 起，前端从 CasaOS 式多窗口桌面改为两个区域：日常使用的**用户页面**和配置
设备的**管理后台**。之前的桌面方案与取舍记录在 [FRONTEND-REDESIGN.md](FRONTEND-REDESIGN.md)。

## 页面划分

| 区域 | 页面 | 地址 | 可见角色 |
| --- | --- | --- | --- |
| 用户 | 首页：问候、文件搜索、继续观看、最近照片、存储空间、应用快捷方式 | `#home` | 全部 |
| 用户 | 文件管理 | `#files` | 全部 |
| 用户 | 相册：照片、相簿、保险箱（保险箱仅设备管理员） | `#album` | 全部 |
| 用户 | 追番：订阅书架、继续观看、剧集与播放 | `#anime` | 全部 |
| 设置 | 我的（个人）：主题、保险箱状态、修改密码、退出登录 | `#me` | 全部 |
| 后台 | 概览：运行模式、内存、存储、任务 | `#admin` | 管理员、操作者 |
| 后台 | 任务中心 | `#admin/jobs` | 管理员、操作者 |
| 后台 | 追番管理：订阅、下载控制、连接与调度、元数据、历史 | `#admin/anime` | 管理员、操作者 |
| 后台 | 相册管理：照片目录、私密目录、整目录分批扫描／缩略图、暂停与恢复 | `#admin/album` | 管理员、操作者（目录配置仅管理员） |
| 后台 | 备份：WebDAV 与本地副本 | `#admin/backup` | 管理员 |
| 后台 | 用户与权限：账号、角色、操作能力表 | `#admin/users` | 管理员 |
| 后台 | 系统设置：存储目录、下载器、运行模式、旧版媒体库 | `#admin/system` | 管理员 |
| 后台 | 操作记录：审计与授权 | `#admin/logs` | 管理员 |

路由表在 `frontend/src/lib/routes.js`。旧的桌面地址仍然有效：`#media` → `#anime`，
`#overview` → `#admin`，`#jobs`、`#settings`、`#backup` → 对应后台页面。无权访问的
地址回到首页；隐藏入口只是界面整理，权限仍由服务端检查（见 [AUTH.md](AUTH.md)）。

## 视觉与布局

界面仿照 Nextcloud：

- **顶栏：** 蓝色背景上的透明顶栏，左边是应用（首页／文件／相册／追番），右边是
  保险箱解锁状态、“管理”入口（有权限时）、主题切换和头像菜单。所有页面共用这一个顶栏，
  切换页面时不会重建，菜单也就不会被中途销毁。
- **应用区：** 顶栏下方是一个圆角的应用区。带导航的应用（文件、相册、设置）左侧是半透明的
  导航列表（胶囊形条目，选中项浅蓝底），右侧是不透明的内容。文件与相册铺满应用区，只在
  内部滚动。
- **设置应用：** 管理后台和“我的”合并为“设置”：左侧导航分“个人”和“管理”（概览、任务、
  内容、数据、系统）两组；内容按 Nextcloud 设置页的样子排成平铺的分区，用分隔线隔开。
  1024px 以下导航收为抽屉。
- **手机：** 应用移到底部五项标签栏（含“我的”），应用区贴边，上方保留圆角。
- **控件：** 胶囊按钮，2px 边框的圆角输入框，开关用原生复选框绘制。颜色、圆角和尺寸集中在
  `styles.css` 顶部的 token 中。没有保存主题时样式表直接跟随 `prefers-color-scheme`，
  首屏不会闪白；“我的”页面可选跟随系统／浅色／深色。
- 系统字体、内联 SVG 图标，不使用在线字体或背景图片（背景是 CSS 渐变）；导航的半透明
  效果用 `backdrop-filter`，不支持的浏览器显示为不透明的浅色。
- 交互组件使用 [Bits UI](https://bits-ui.com)（Svelte 5 无样式组件库，版本固定在
  `package.json`）：它只提供键盘、焦点和无障碍行为，外观仍由 `styles.css` 决定，按需打包，
  不引入 Tailwind。目前用于可展开的错误详情（Collapsible）和头像账号菜单（DropdownMenu）。
  菜单关闭了 Bits UI 默认的页面滚动锁（`preventScroll={false}`）：那把锁通过
  `body { pointer-events: none }` 实现，曾在菜单关闭后残留，导致整页无法点击。
- 错误统一用 `ErrorNotice`：第一行是摘要，服务端提供的技术细节（步骤、HTTP 状态、服务器
  回复、错误代码）在“查看详情”中展开，可复制。内部错误原文只返回给设备管理员。
- 可以“添加到主屏幕”：提供 `manifest.webmanifest` 与 192/512/maskable 图标，以独立窗口打开。

## 状态保留与运行成本

访问过的页面保持挂载、隐藏显示，所以切换页面（包括在用户页面和后台之间）不会丢失
未保存的草稿、进行中的上传或播放。只挂载访问过的页面；隐藏页面通过可见性上下文跳过
轮询。页面里的对话框属于该页面，打开时覆盖视口；关闭保护沿用各功能已有的逻辑。
登录前不挂载受保护内容，退出或 API 会话失效时卸载全部页面。

前端编译产物在 internal/hubweb/web，Go 直接嵌入；部署不跑 Node。修改前端才需要在
开发机执行 npm ci、npm run check、npm run build。构建给脚本／样式 URL 添加内容摘要；
带正确摘要的请求按 immutable 缓存一年，index.html 每次重新验证，升级后自然换新。
浏览器支持时以 gzip 发送（脚本约 330 KB → 110 KB），压缩结果在首次请求时生成一次并
保留；ETag 在启动时按内容计算，不再每次请求都对整个文件做哈希。
API 默认 20 秒超时，卸载取消请求；概览数据只在首页和后台概览可见时每 15 秒刷新一次，
浏览器隐藏时跳过。浏览不会发起媒体扫描、解码或转码。

浏览器仅保存主题、文件视图偏好及用户明确固定的目录元数据。标签、最近使用、草稿
只在当前页面实例中保留；不向 localStorage 写入令牌或文件内容。

## 验证

Svelte 检查要求零错误、零警告。DOM 测试使用真实编译脚本和隔离 Go 服务：
`shell.mjs` 覆盖路由与角色、页面保活与草稿、后台抽屉、主题与会话失效；其余脚本覆盖
文件、相册、追番、备份、设置和账号流程（见 `scripts/uitest`）。真实浏览器另外检查
宽屏、手机和深色布局。jsdom 不提供视觉或编码播放证据；真实 NAS 资源、真实下载器和
长期运行仍需部署验证。
