# 桌面与文件管理器改版计划

状态：2026-10-14 已完成 agy / Claude Opus 5.5 (High) 文字评审及本轮视觉实现。依据用户提供的 CasaOS 桌面
参考图和 P2 文件管理器参考图。本轮只改视觉与本地文件交互；网盘连接留到按需接入。

## 方向与保留项

桌面采用山景背景、左侧状态组件、右侧应用区与底部窗口切换，减少后台仪表盘感。
文件窗口采用原生文件管理器的布局：位置侧栏、标签页、导航／路径工具栏、网格／列表、
可收起的预览详情栏和底部状态。保留多应用窗口及其草稿、上传、播放关闭保护。

不画缺少 API 支持的 CPU、吞吐或磁盘容量；只展示真实的内存、根目录和任务状态。
文件目录与搜索继续分页、有界；图片只在选中预览时请求，不在网格中并发读取全部原图。
后端根目录边界、只读和 AI 身份限制、拒绝覆盖、回收恢复和永久删除确认全部保留。

## 实施顺序

| 步骤 | 交付物 | 验收条件 |
| --- | --- | --- |
| 1. 视觉基线 | 桌面／文件窗口的色彩、尺寸、布局断点、图标与壁纸方案 | 对应两张参考图的结构，确认低资源和真实状态边界 |
| 2. 桌面外观 | 原创内置背景、状态侧列、应用图标区、应用搜索和真实任务摘要 | 搜索能筛选并打开应用；不依赖外部字体、图片或大型 UI 库 |
| 3. 文件窗口结构 | 位置栏、标签栏、路径工具栏、默认网格、可切换列表和状态栏 | 内容铺满功能窗口；根目录、子目录、搜索和分页均读真实 API |
| 4. 文件导航 | 后退／前进／主目录、多个位置标签、用户固定目录、会话内最近使用 | 各标签保留位置和查询；固定项指向合法配置根目录；单击选择、双击／Enter 打开 |
| 5. 详情与本地操作 | 可收起详情栏、右键／更多菜单、选中操作、完整回收站流程 | 原有上传、建目录、下载、复制、移动／改名、回收／恢复／确认清理可用；只读正确禁用 |
| 6. 响应式与无障碍 | 手机位置抽屉和详情面板、键盘选择／菜单、焦点管理 | 窄窗口与手机不整页溢出；对话框仍只影响所属应用；切换窗口不丢操作状态 |
| 7. 回归与交付 | Svelte 检查、真实 API DOM 回归、浏览器截图、更新本机预览与文档 | 文件字节与拒绝覆盖行为保持正确；桌面／文件／手机流程通过，明确未验证的 NAS 项 |

## 讨论记录

通过本机 agy 的 `claude-opus-5-5-high` 完成文字评审；仅发送整理后的需求简报，
没有源码、凭据、实际文件路径或项目目录访问权限。

采纳意见：重做信息层级；窗口内容用不透明表面，透明仅用于桌面组件；文件项不常驻
操作按钮，使用选中工具栏、菜单和详情；网格用类型色和扩展名图标；按窗口宽度响应；
详情延迟 150ms 并取消旧请求，视频/音频 preload=none；位置标签上限 8、历史有界；
不展示缺少可靠 API 的设备数据。

实施取舍：保留现有分页以保持内存有界；触屏提供明确的打开及更多操作入口；文件搜索
明确根目录范围。固定目录与视图偏好在本机浏览器保存，最近使用仅保留在文件应用会话。

尺寸基准：桌面侧列 240px、组件间距 16px、图标 56px；文件位置栏 180px、详情栏
240px、标签栏 36px、工具栏 48px、状态栏 28px。文件窗口小于 960px 时详情覆盖，
小于 720px 时位置栏收起。浅色窗口白底，深色窗口 #171B26；文件选中使用蓝色。

## 本轮验证

已实现上述桌面和文件交互。Svelte 零错误、零警告；真实 API DOM 验证导航、选择、
历史、标签上限、固定／最近使用、键盘菜单、应用／文件搜索及全部原有文件写入流程，
包括 XHR 上传字节、同名拒绝覆盖、复制移动、回收恢复与永久删除的准确名称确认。
登录与多窗口草稿保护回归通过，Go hubweb 竞态测试通过。

真实浏览器检查了 1280×720 桌面、390×844 与 360×740 手机和约 480px 宽功能窗口；
手机与窄窗口测得文件区域 scrollWidth 等于 clientWidth，位置抽屉 Escape 可关闭并
恢复焦点。壁纸组件源码 gzip 约 1 KiB，无外部背景请求。长期运行和实际 NAS 仍待验证。
