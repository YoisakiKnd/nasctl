# nasctl 功能完成清单

目标是低资源、多架构、可日常使用的个人 NAS。追番参考 AutoBangumi 的订阅、下载、
刮削、整理与媒体库流程；文件管理参考 CasaOS 的常用操作。保留 albumctl，采用 Svelte
控制台，不要求 Telegram，也不局限于 ARMv7。此清单记录尚待完成与验证的工作，不能
以页面存在或交叉编译成功代替实际功能验收。
