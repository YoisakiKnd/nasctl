# WebDAV 备份

在“备份 → WebDAV”连接一个已存在的远端文件夹，再选择 NAS 上已配置的文件或文件夹。
连接需支持 PROPFIND、MKCOL、PUT、GET、MOVE（Overwrite: F）和临时上传的 DELETE。
默认要求 HTTPS；可信局域网的 HTTP 必须在连接设置中显式启用。不跟随重定向，也不把凭据交给系统代理。

## 两种方式

- **直接上传**：原文件按目录结构写入独立版本目录，内容不压缩、不加密。远端包含 `data/` 原文件和带 SHA-256 的 `manifest.json`。
- **加密压缩包**：Go 的 `archive/tar` → `github.com/klauspost/compress/zstd` → `filippo.io/age`，生成随机名称的 `.tar.zst.age`。文件内容和内部文件名都在加密层内，不上传明文 tar 或 zstd 文件。

两种方式均保留本地原文件，包含隐藏文件，跳过符号链接、特殊文件和系统保留目录。上传到随机临时位置后，逐文件或整包回读 SHA-256 校验，通过 MOVE 发布版本；不会覆盖既有备份，也不会自动清理远端版本。

加密密码至少 12 个字符，建议使用较长的随机密码或多个随机词。密码只在任务内存中使用，不写入配置、任务参数、历史或状态包。NAS 无法找回遗失的备份密码。WebDAV 登录密码与加密包密码互相独立。

## 保险箱

“照片保险箱（加密数据）”是单独的备份源，只允许加密压缩包。它导出一致的 `vault.json` 与现有密文，不解密原图、缩略图或文件名。正在移入、尚未完成原件清理时拒绝导出，同时暂停普通文件直接上传，避免把尚待清理的原件传到远端。

移入保险箱不会撤回此前已经创建或开始的普通备份；私密内容应先移入保险箱，或直接选择加密压缩包。

恢复此备份会得到保险箱的加密文件；它们仍需**原保险箱密码**。备份包密码只打开外层归档。要导回相册：先停机，保留原保险箱目录，按原目录权限（目录 0700、文件 0600）把恢复文件放入状态目录的 `.nasctl-photo-vault`，再启动 nasctl。不要把两个保险箱的文件合并，也不要覆盖尚未备份的原目录。

## 恢复与失败重试

在“我的备份”中选择“恢复”，指定可写存储中的新目录。加密包需要输入创建时的备份密码。只接受受限目录、普通文件和合法相对路径；拒绝链接、路径穿越、重复条目、损坏或超预算数据。验证传输与解密后才发布新目录，不覆盖同名目标。保留拍摄文件时间；恢复文件默认以私有权限创建。

加密包还可以下载后离线打开：

```sh
age --decrypt --output backup.tar.zst downloaded.tar.zst.age
zstd --decompress backup.tar.zst
# 在一个新的空目录中解包；先检查 tar 清单。
tar --list --file backup.tar
tar --extract --file backup.tar --directory new-empty-directory
```

这些工具仅用于可选的离线恢复，NAS 备份和网页恢复不依赖外部命令。

加密包上传失败时保留私有密文暂存文件，可直接重试上传，不必再次提供密码；若尚未完成压缩，则需要重新创建备份。普通文件失败时从原文件重新开始。重启把未完成记录标为已中断；不会把 `.part` 位置当作有效版本。远端不支持清理时可能遗留临时位置，可确认后在 WebDAV 服务中手动处理。

## 资源与权限

同一时间只执行一个本地/WebDAV 备份或恢复任务，沿用 NAS 资源保护与停止任务机制。默认遵守存储的条目、字节和最长时间预算；目录深度最多 32。zstd 使用单并发、最快级别和 1 MiB 窗口；age scrypt 工作因子为 15（约 32 MiB KDF 内存），避免密码派生独占低内存设备。恢复限制 scrypt 工作因子、zstd 解码窗口和总输出预算。

加密包暂存在状态目录 `.nasctl-webdav`，只有密文，成功后删除。写入时为状态盘保留至少 64 MiB 余量；这不代替设备自己的磁盘配额。原样上传不在 NAS 产生打包暂存文件。本机最多保存 128 条备份记录，达到上限时停止创建新版本；远端已有版本不会被删除。

WebDAV 管理只供 NAS 管理员使用，AI 和普通成员不能读取连接或发起上传。登录密码仅保存在本机私有配置，API 只返回“已设置”。**离线状态备份包含无密码的版本历史和桌面应用链接，不包含 WebDAV 登录凭据或失败任务的密文暂存包**；状态恢复后需重新填写 WebDAV 连接。保持原地址与用户名即可识别历史版本。
