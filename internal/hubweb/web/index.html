Album

Album

The album module reads the index built by albumctl. In this stage the console does not create that index, and it does not scan, decode or generate thumbnails inside a request.

To browse the album, run albumctl scan and albumctl thumbs on this machine, then reload. The album service serves the photo timeline at its own address.

Backup

Backup

The console reports on the existing backup and yields to it. It never starts, stops, reconfigures or accelerates it, and it does not change the copy to a sync, a move or a delete.

Backup status reporting is delivered with the task layer; this page shows only what the configured status command returns.
